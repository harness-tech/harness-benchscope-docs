# v1.0.6

## Release Information

| Item | Value |
| --- | --- |
| Version | **1.0.6** |
| Status | Released (PyPI `benchscope==1.0.6`) |
| Release date | 2026-08-28 |

**v1.0.6 is an iterative development version** focused on **Datas as the primary navigation** (performance / accuracy record management and comparative analysis), the **built-in datasets module**, and **expanded cache paths** (model / data directories unified under `~/.benchscope`).

## Main Capabilities

### Datas primary navigation

Datas became the primary record hub with **Perfs / Evals dual tabs**:

- **Perfs** — paginated records table + **best-test-record highlight** (best performance, gold **Best** marker) + performance data details (mean / median / P99 triplets for Output / TTFT / TPOT / ITL) + **comparative analysis of multiple selected records**.
- **Evals** — placeholder (filled in by the accuracy module in v1.0.8).

![Performance record statistics](/images/benchscope-datas-perfs_statistics.png)

See [Datas](/en/docs/data/).

### Built-in datasets module (Settings → Datasets)

- Defined in **`datasets.yaml`**.
- Downloaded from **modelscope** or a **url source**.
- Cached to `data_dir/datasets/{id}/`.

### Expanded cache paths

- Added the **`models_dir`** config (default `~/.benchscope/models`).

### Directory configuration system

- **9 unified directories**, persisted in **`settings.json`**, with the **Cache Paths** panel reworked.

## Notes

- This release unified the data layout under `~/.benchscope`; see [Configuration](/en/docs/install/configuration/) for the full subdirectory map.
- Settings continued to migrate to `settings.json` (the legacy `config.json` remains auto-migrated).
