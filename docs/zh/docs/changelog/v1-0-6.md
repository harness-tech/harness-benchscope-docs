1.0.6 为迭代开发版本，规划重点是 **Datas 主导航**（性能 / 精度记录管理与对比分析）、**内置数据集模块**、**缓存路径扩充**（模型 / 数据目录统一到 `~/.benchscope`）。

## 主要能力

### Datas 主导航

- **Perfs / Evals 双 Tab**；
- **Perfs**：
  - 分页记录表 + **最佳测试记录高亮**（性能最佳，金色 **Best** 标记）；
  - **性能数据详情**：Output / TTFT / TPOT / ITL 的 **mean / median / p99 三元组**；
  - **多选记录对比分析**；
- **Evals**：占位（后续版本落地）。

### 内置数据集模块

- **Settings → Datasets**：`datasets.yaml` 定义；
- 下载（**modelscope** 或 **url 源**）与缓存到 `data_dir/datasets/{id}/`。

### 缓存路径扩充

- 新增 **`models_dir`** 配置（默认 `~/.benchscope/models`）。

### 目录配置体系

- **9 目录统一**，`settings.json` 持久化，Cache Paths 面板改造。
