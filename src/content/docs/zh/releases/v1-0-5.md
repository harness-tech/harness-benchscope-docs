# v1.0.5

| 项目 | 内容 |
| --- | --- |
| 版本 | 1.0.5 |
| 状态 | 迭代开发版本（后续迭代并入后续版本） |
| 发布日期 | —（迭代开发） |

v1.0.5 为 **v2.0 UI 大改 + 性能页双模式增强** 版本，是后续版本 UI 与交互的基础。

## 主要能力

### v2.0 UI 大改

- **5 栏导航**：Dashboard / Performance / Accuracy / Sessions / Settings；
- **任务化 Performance**：多任务持久化；
- **Sessions SSE 对话**；
- **Settings 分区设置**；
- **i18n（中 / 英）** + **亮 / 暗 / 跟随系统**主题。

### 任务双模式

- `concurrency`（多档并发压测）/ `threshold`（阈值探测，逐级倍增 + 二分寻找满足阈值的最大并发）。

### 创建任务三步表单

- **Step1 条件 / Step2 参数 / Step3 命令预览**；
- `?mode=` 区分模式。

### Realtime 分组表格

- 按 case 分组、组内并发升序；
- 每组独立 **Best / BestPerf 唯一高亮**；
- **本地阈值试算**。

### Excel 导出

- 含分组标题行与 **Best / BestPerf** 标记。

### Dashboard 重构

- **Overview 六宫格** + **Envs info** + **Perf/Eval Records**。

### mock 环境

- `mocks/` 包支持链路联调。
