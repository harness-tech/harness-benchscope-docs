# Documentation

Welcome to **BenchScope** — an open-source platform for running **performance stress tests** and **accuracy evaluations** on models (and OpenAI-compatible inference services). This manual is organized into five groups — "**Quick Start → Testing → Platform → Reference → Community**" — covering everything from first use to deep tuning.

## Quick Start

- [Quick Start](/en/docs/quickstart/) — learn what BenchScope is and what it can do, and start here
- [Install](/en/docs/install/) — environment requirements, startup, configuration, update & uninstall

## Testing

- [Performance Testing](/en/docs/performance/) — performance testing and stress testing (concurrency / threshold dual modes), including [Performance Core Metrics](/en/docs/performance/metrics/)
- [Accuracy Testing](/en/docs/accuracy/) — accuracy testing and evaluation (Native / Serving / Mock three modes), including [Accuracy Core Metrics](/en/docs/accuracy/metrics/)

## Platform

- [Dashboard Overview](/en/docs/tools/dashboard/) — resource counts, environment info, and latest performance records

- [Settings](/en/docs/tools/settings/) — global configuration (Provider / models / datasets / engines / skills / plugins)
- [Built-in Skills](/en/docs/tools/skills/) — the 3 Agent skills shipped with the package

- [Bench Engine](/en/docs/tools/bench-engine/) — engine abstraction, comparison, and customization
