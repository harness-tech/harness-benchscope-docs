# v1.1.0

## Release Information

| Item | Value |
| --- | --- |
| Version | **1.1.0** |
| Status | Released |
| Release date | 2026-09-05 |

1.1.0 is a minor version upgrade following **1.0.8** (which delivered the standalone accuracy testing module). It covers enhancements to the **session experience**, the **performance real-time panel**, the **Dashboard overview and environment info**, as well as a **consolidated Settings / Datas display**.

## Feature Highlights

### Performance page real-time panel

- A **dual panel on the second row** (Realtime Data / Profile Progress / Real-Time Metrics).
- **Per-request real-time snapshot persistence** — viewable in Datas / Perfs details.
- The **Native engine** updates per concurrency point while running, with **continuous scrolling** within a single concurrency point.

![Performance running statistics](/images/benchscope-performance_perf_running_statistics.png)

### Per-request snapshots

- Per-request snapshots were **extended to the Native engine**.
- Metric definitions are **aligned to vLLM** for cross-engine comparability, and the engine import logic was hardened.

### Third-party engine metric availability

- **Available** → value (blue) / **unavailable** → N/A (gray-black) / **missing** → gray dash.
- A **fixed 11-metric snapshot contract** guarantees a consistent output structure from every engine.

### Sessions experience

- **Sampling parameters**, Markdown rendering + code highlighting (highlight.js + dark theme).
- **Renaming** + session log storage, a refined sidebar, and a **centered confirmation dialog** for clearing.

See [Sessions](/en/docs/tools/sessions/) for the resulting UX.

### Settings refinements

- **Cache Paths reworked**: Root Dir takes effect immediately, subdirectories are read-only.
- Four categories of UI refinements.
- **Bench engine cards color-coded by source**.
- **Green labels for Provider models**.

### Dashboard Overview rebuild

Rebuilt into **7 count panels**: Performance / Accuracy / Sessions / Skills / Models / Datasets / Providers.

![Dashboard overview](/images/benchscope-dashboard.png)

### Dashboard Envs info completion

- Shows **MAC / IP / subnet / mask** per network interface.
- Plus **framework version**, **hardware**, and **operating-system** information.
- A **“Coming Soon” placeholder** for unfinished panels.

### Datas navigation

- The **Evals tab is hidden** (its route redirects to Perfs); **Analysis is a placeholder**.
- The Accuracy **“Create Task”** shows a **Coming Soon** dialog in this release.

## Notes

- If you are upgrading from a version before 1.0.8, note that the accuracy module is now available (see the [v1.0.8](/en/docs/releases/v1-0-8/) notes).
- Configuration continues to persist automatically to `settings.json` — no migration steps are required.
