## 升级提示

- 升级后建议**重启服务**；
- 旧版 `~/.benchscope/config.json` 会自动迁移为 `settings.json`，无需手动处理；
- 升级前建议先备份数据根目录（见 [安装 → 更新与卸载](/zh/docs/install/update-uninstall/)）。
