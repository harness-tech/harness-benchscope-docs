1.0.7 的主目标：**性能测试核心引擎改造** —— 引擎抽象与自研 bench。

## 主要能力

### 自研 bench（benchscope 引擎）

- 基于 vLLM / SGLang bench 思路实现**自研测试引擎**；
- **不依赖本地框架环境**，`pip` 安装即可远程测 OpenAI 兼容服务。

### 引擎版本化

- 支持指定具体版本的 **vLLM**（如 `vllm-0.23`）与 **SGLang**（如 `sglang-0.5.10`）原生 bench。

### 参数下拉 + 描述

- 各引擎参数**独立设置**、**下拉选择**并展示描述。

### Settings → Bench 配置栏

- 内置 `benchscope` / `vllm-0.23` / `sglang-0.5.10`，含**介绍与对比**；
- 每引擎 **Mock 开关**。

## 环境校验约定（强制）

- **原生引擎**（vllm / sglang）：必须校验 **torch 与 vllm / sglang 安装版本**，不满足 → **禁止进入下一步**；
- **自研 bench**：无需上述环境，本地安装即可测远程 API。

::: warning
选择原生引擎前请先确认本机已安装匹配的 torch 与框架版本，否则流程会被强制阻断。
:::
