# Tools

The Tools section covers BenchScope's **advanced usage and platform-level capabilities**: session-based interaction, global settings, and, for developers, the architecture and engine abstraction.

- **[Sessions](/en/docs/tools/sessions/)** — SSE-streaming interactive chat: sampling parameters, Markdown rendering, reasoning parsing, and a performance bar.
- **[Settings](/en/docs/tools/settings/)** — seven panels for global configuration: Providers / Models / Datasets / Bench Engines / Skills / Plugins.
- **[Architecture](/en/docs/tools/architecture/)** — the single-process Python (FastAPI) + Vue architecture, core modules, and data flow.
- **[Bench Engine](/en/docs/tools/bench-engine/)** — the engine abstraction: unified integration of the built-in / vLLM / SGLang / custom engines.

## When to use it

- To **chat interactively** with a model in the browser → see [Sessions](/en/docs/tools/sessions/).
- To configure inference providers, model lists, datasets, and engines → see [Settings](/en/docs/tools/settings/).
- To understand or extend the BenchScope codebase → see [Architecture](/en/docs/tools/architecture/) and [Bench Engine](/en/docs/tools/bench-engine/).
