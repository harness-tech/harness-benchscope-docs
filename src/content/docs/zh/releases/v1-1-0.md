# v1.1.0

| 项目 | 内容 |
| --- | --- |
| 版本 | 1.1.0 |
| 状态 | 已发布（Released） |
| 发布日期 | 2026-09-05 |

1.1.0 是 1.0.8（独立精度测试模块）之后的一次主 / 次版本升级，涵盖**会话体验、性能实时面板、Dashboard 概览与环境信息**等增强，并做了 Settings / Datas 的展示收敛。

<div class="tip">

**tip**：

升级后建议重启服务。若从更早版本升级，数据会自动迁移（`config.json` → `settings.json`），无需手动处理。

</div>

## 特性亮点

### 性能页实时面板

- 第二行**双面板**（Realtime Data / Profile Progress / Real-Time Metrics）；
- **一请求级实时快照**持久化（可在 Datas / Perfs 详情查看）；
- 原生引擎运行中随并发点更新，单并发点内**连续滚动**。

### 单请求快照

- 按请求快照**拓展到原生引擎**；
- 指标口径对齐 vLLM，保证跨引擎可比；
- 引擎导入逻辑加固。

### 第三方引擎指标可得性

- 可得 → 值（蓝）；不可得 → N/A（灰黑）；缺失 → 灰横线；
- 固定 **11 指标快照契约**，保证结构一致。

### Sessions 会话体验

- **采样参数**、**Markdown 渲染 + 代码高亮**（highlight.js + 深色主题）；
- **重命名 + 会话日志落盘**、侧栏细化；
- 清空操作带**居中确认弹窗**。

### Settings 细化

- **Cache Paths 改版**：Root Dir 即时生效、子目录只读；
- 四类 UI 细化；**Bench 引擎卡片按来源标色**；Provider 模型**绿色标签**。

### Dashboard Overview 重构

- 重建为 **7 计数面板**（Performance / Accuracy / Sessions / Skills / Models / Datasets / Providers）。

### Dashboard Envs info 补全

- 按网口展示 **MAC / IP / 子网 / 掩码**；
- 框架版本、硬件、操作系统信息；
- 未完成面板以「敬请期待」占位。

### Datas 导航收敛

- 隐藏 Evals Tab（路由重定向至 Perfs）、Analysis 占位；
- Accuracy「创建任务」显示「敬请期待」弹窗。
