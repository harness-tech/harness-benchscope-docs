# v1.0.8

## Release Information

| Item | Value |
| --- | --- |
| Version | **1.0.8** |
| Status | Released (a patch release, not pushed to PyPI) |
| Release date | 2026-09-01 |

**v1.0.8’s main goal: delivering the standalone accuracy testing module (Accuracy)** — a **dual-mode evaluation loop** of *“Native accuracy + Serving pipeline accuracy”*. See [Accuracy Testing](/en/docs/accuracy/) for how to use it.

## Main Capabilities

### Dual modes

- **Native** (engine `native-hf`) — loads weights locally (transformers / HF id) for offline evaluation, with **LoRA adapter** support.
- **Serving pipeline** (engine `serving`) — calls an OpenAI-compatible inference service for **real-pipeline** evaluation.

### 9 specialized datasets

Full coverage of **knowledge / math / code / chat / Chinese** domains, including:

- **HumanEval / MBPP** code-sandbox `pass@1`
- **MT-Bench** LLM-as-judge

### Scorers

`choice` / `math` / `code` / `judge`, and so on, with full coverage of standard accuracy metrics.

### Open-source baseline comparison

- **Baseline library** + **tier rating** + **capability radar chart**.

### Token estimation

- Full **token-consumption estimation** for Serving mode + strong reminders + **actual statistics** after the run — see [Token Estimation](/en/docs/accuracy/).

### Built-in command

Added **`benchscope eval`** to the CLI — see the [CLI Reference](/en/docs/cli/reference/).

### Fully independent

The accuracy module is **decoupled from the performance module** and forms its own loop (independent tasks / results / scheduling).

## Hard Constraints

- **Native does not force the installation** of torch / transformers — it only **detects existing dependencies** and blocks if they are not satisfied.
- The **accuracy module contains no performance metrics** — accuracy and performance are cleanly separated.

## Notes

- This release focused entirely on the accuracy module; performance testing was unaffected.
- If you want to try accuracy with local weights, install the optional extra with:

  ```bash
  pip install benchscope[accuracy-native]
  ```
