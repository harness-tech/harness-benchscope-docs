# v1.0.7

| 项目 | 内容 |

v1.0.7 的主目标：**性能测试核心引擎改造** —— 引擎抽象与自研 bench。本版本引入了此后一直沿用的可插拔引擎模型。

## 主要能力

### 自研 bench（benchscope 引擎）

- 基于 **vLLM / SGLang bench** 思路实现**自研测试引擎**；
- **不依赖本地框架环境**，`pip` 安装即可**远程**测 OpenAI 兼容服务。

```bash
pip install benchscope
benchscope perf --model Qwen2.5-7B --base-url http://127.0.0.1:8000
```

### 引擎版本化

- 支持指定具体版本的 **vLLM**（如 `vllm-0.23`）与 **SGLang**（如 `sglang-0.5.10`）原生 bench。

### 参数下拉 + 描述

- 各引擎参数**独立设置**、**下拉选择**并展示描述。

### Settings → Bench 配置栏

- 内置 **`benchscope`** / **`vllm-0.23`** / **`sglang-0.5.10`**，含介绍与对比；
- 每引擎 **Mock 开关**。

参见 [设置（Settings）→ Bench Engines](/zh/docs/tools/settings/)。

## 环境校验约定（强制）

- **原生引擎（vllm / sglang）**：必须校验所安装的 **torch 与 vllm / sglang 版本**，不满足 → **禁止进入下一步**；
- **自研 bench**：无需上述环境，本地安装即可测远程 API。

<div class="warning">

**warning**：

依赖原生 vLLM / SGLang 引擎时，请先确认本机已安装匹配的框架版本，否则任务会被环境校验强制阻断。

</div>
