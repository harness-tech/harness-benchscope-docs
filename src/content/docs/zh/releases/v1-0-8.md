# v1.0.8

## 发布信息

| 项目 | 内容 |
| --- | --- |
| 版本 | 1.0.8 |
| 状态 | 已发布（Released，补丁发布，未推 PyPI） |
| 发布日期 | 2026-09-01 |

v1.0.8 的主目标：**独立精度测试模块（Accuracy）落地** —— **「Native 原生精度 + Serving 链路精度」双模式评测闭环**。使用方法见 [概述](/zh/docs/accuracy/)。

## 主要能力

### 双模式评测

- **Native 原生**（引擎 `native-hf`）：本地加载权重（transformers / HF id），**离线评测**，支持 **LoRA 适配器**；
- **Serving 链路**（引擎 `serving`）：调用 OpenAI 兼容推理服务，进行**真实链路**评测。

### 9 个专项数据集

知识 / 数学 / 代码 / 对话 / 中文专项全覆盖，包括：

- **HumanEval / MBPP** 代码沙箱 `pass@1`；
- **MT-Bench**（LLM-as-judge）。

### 判分器

`choice` / `math` / `code` / `judge` 等，标准精度指标全覆盖。

### 开源基线对标

- **基线库** + **档位评级** + **能力雷达图**。

### Token 预估

- Serving 模式**全量 Token 消耗预估** + 强提醒 + 运行后**实统计** —— 见 [Token 预估](/zh/docs/accuracy/modes/)。

### 内置命令

- 新增 **`benchscope eval`** CLI 命令。

### 完全独立

精度模块与性能模块**解耦**，自成闭环（独立任务 / 结果 / 调度）。

## 硬性约束

- Native **不强制安装** torch / transformers，仅**检测已有依赖**，不满足则**阻断**；
- 精度模块**不含任何性能指标**，与性能模块严格区分。

## 备注

- 本版本专注于精度模块，性能测试不受影响。
- 想用本地权重体验精度评测，可安装可选额外依赖：

  ```bash
  pip install benchscope[accuracy-native]
  ```
