# v1.0.5

## 发布信息

| 项目 | 内容 |
| --- | --- |
| 版本 | 1.0.5 |
| 状态 | 迭代开发版本（后续迭代并入后续版本） |
| 发布日期 | —（迭代开发） |

v1.0.5 是 **v2.0 UI 大改 + 性能页双模式增强** 版本，奠定了 BenchScope 当前的视觉风格，并引入了此后一直沿用的两种性能测试模式。

## 主要能力

### v2.0 UI 大改

- **5 栏导航**：Dashboard / Performance / Accuracy / Sessions / Settings；
- **任务化 Performance**：多任务持久化；
- **Sessions SSE 对话**；
- **Settings 分区设置**；
- **i18n（中 / 英）** + **亮 / 暗 / 跟随系统**主题。

### 任务双模式

- **`concurrency`**（多档并发压测）；
- **`threshold`**（阈值探测，逐级倍增 + 二分寻找满足阈值的最大并发）。

这与 [性能测试](/zh/docs/performance/) 中描述的两个模式一致。

### 创建任务三步表单

- **Step1 条件 / Step2 参数 / Step3 命令预览**；
- 通过 `?mode=` 在 URL 中区分模式。

### Realtime 分组表格

- 按 case 分组、组内并发升序；
- 每组独立 **Best / BestPerf 唯一高亮**；
- **本地阈值试算**。

### Excel 导出

- 含分组标题行与 **Best / BestPerf** 标记。

### Dashboard 重构

- **Overview 六宫格** + **Envs info** + **Perf/Eval Records**。

### mock 环境

- `mocks/` 包支持链路联调。

## 备注

- 作为**迭代开发**版本，后续迭代并入后续版本（尤其是 v1.0.6 的 Datas 改造与 v1.0.7 的引擎改造）。
- 若需回溯双模式性能测试的设计，本版本正是引入它的起点。
