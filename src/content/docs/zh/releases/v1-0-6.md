# v1.0.6

## 发布信息

| 项目 | 内容 |
| --- | --- |
| 版本 | 1.0.6 |
| 状态 | 已发布（Released，PyPI `benchscope==1.0.6`） |
| 发布日期 | 2026-08-28 |

v1.0.6 为迭代开发版本，规划重点是 **Datas 主导航**（性能 / 精度记录管理与对比分析）、**内置数据集模块**、**缓存路径扩充**（模型 / 数据目录统一到 `~/.benchscope`）。

## 主要能力

### Datas 主导航

Datas 成为记录管理主入口，含 **Perfs / Evals 双 Tab**：

- **Perfs**：分页记录表 + **最佳测试记录高亮**（性能最佳，金色 **Best** 标记）+ 性能数据详情（Output / TTFT / TPOT / ITL 的 **mean / median / p99 三元组**）+ **多选记录对比分析**；
- **Evals**：占位（由 v1.0.8 的精度模块落地）。

![性能记录统计](/images/benchscope-datas-perfs_statistics.png)

参见 [数据与统计（Datas）](/zh/docs/data/)。

### 内置数据集模块（Settings → Datasets）

- 由 **`datasets.yaml`** 定义；
- 从 **modelscope** 或 **url 源** 下载；
- 缓存到 `data_dir/datasets/{id}/`。

### 缓存路径扩充

- 新增 **`models_dir`** 配置（默认 `~/.benchscope/models`）。

### 目录配置体系

- **9 目录统一**，持久化到 **`settings.json`**，并重构 **Cache Paths** 面板。

## 备注

- 本版本将数据布局统一到 `~/.benchscope`，完整子目录映射见 [配置](/zh/docs/install/configuration/)。
- Settings 持续迁移至 `settings.json`（旧版 `config.json` 仍会自动迁移）。
