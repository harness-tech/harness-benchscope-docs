# 工具（高级）

工具区收录 BenchScope 的**进阶使用与高级能力**：会话式交互、全局设置，以及面向开发者的架构与引擎抽象。

- **[会话（Sessions）](/zh/docs/tools/sessions/)** — 基于 SSE 流式的交互式对话：采样参数、Markdown 渲染、思考解析与性能栏。
- **[设置（Settings）](/zh/docs/tools/settings/)** — 七个面板集中管理全局配置：Providers / Models / Datasets / Bench Engines / Skills / Plugins。
- **[架构介绍](/zh/docs/tools/architecture/)** — 后端 Python（FastAPI）+ 前端 Vue 的单体架构、核心模块与数据流。
- **[Bench 引擎](/zh/docs/tools/bench-engine/)** — 引擎抽象与自定义：自研 / vLLM / SGLang / 自定义引擎的统一接入。

## 适用场景

- 想在浏览器里与模型**交互式对话** → 看 [Sessions](/zh/docs/tools/sessions/)。
- 想配置推理服务、模型清单、数据集与引擎 → 看 [Settings](/zh/docs/tools/settings/)。
- 想理解 / 扩展 BenchScope 代码 → 看 [架构](/zh/docs/tools/architecture/) 与 [Bench 引擎](/zh/docs/tools/bench-engine/)。
