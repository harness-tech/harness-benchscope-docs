# v1.0.5

## Release Information

| Item | Value |
| --- | --- |
| Version | **1.0.5** |
| Status | Iterative development version (later iterations merged into subsequent versions) |
| Release date | — |

**v1.0.5 is the v2.0 major UI overhaul + performance page dual-mode enhancement release.** It introduced the current look-and-feel of BenchScope and the two performance-testing modes used ever since.

## Main Capabilities

### v2.0 UI overhaul

- **5-column navigation**: Dashboard / Performance / Accuracy / Sessions / Settings.
- **Task-based Performance** — multi-task persistence.
- **Sessions SSE chat**.
- **Partitioned Settings**.
- **i18n** (Chinese / English).
- **Light / dark / follow-system themes**.

### Dual task modes

- **`concurrency`** — multi-level concurrency testing.
- **`threshold`** — threshold probing: doubling level by level (powers of 2 + bisection) to find the maximum concurrency satisfying the threshold.

These are the same two modes described in [Performance Testing](/en/docs/performance/).

### Three-step create-task form

- Step 1 **conditions** / Step 2 **parameters** / Step 3 **command preview**.
- `?mode=` distinguishes the mode in the URL.

### Realtime grouped table

- **Grouped by case**, concurrency in **ascending order within each group**.
- A unique **Best / BestPerf highlight** per group.
- **Local threshold trial calculation**.

### Excel export

- Includes **grouped header rows** and **Best / BestPerf markers**.

### Dashboard rebuild

- **Overview six-grid** + **Envs info** + **Perf/Eval Records**.

### Mock environment

- The **`mocks/` package** supports pipeline integration testing.

## Notes

- As an *iterative* development version, later iterations were merged into subsequent versions (notably v1.0.6’s Datas rework and v1.0.7’s engine rework).
- If you are inspecting history for the dual-mode performance testing design, this is the release that introduced it.
